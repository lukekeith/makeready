## 📱 iPhone app — user-facing

### 1. Edit an enrollment — NEW (biggest change) · monday#12270302158
Leaders can now change an existing enrollment, not just create/delete one.
- **Tap an enrollment → action menu** with **Edit lessons** / **Edit enrollment**. Reachable from **three** places: Program Home, **Groups → Enrolled** tab, and a **Member's** home.
- **Edit enrollment** flow: change the **group**, the **study/program**, and the **schedule — days of week, time, and start date** — with a **preview of what will change** before you Save.
- The action menu also shows an **FYI note** (when the study was made by another leader and you can't edit it) and a **Preview study** option.
- **"Edit enrollment" is disabled** for enrollments you don't manage (another leader's), with a managed-groups fallback until the server flag deploys.
- Fixes along the way: pickers **pre-select the current group/study**; **drilldown transitions + back chevrons** corrected; **no more infinite spinner** when a group's join code is null; **Save button**, program selectability, and the schedule "ghost" preview corrected.

**QA:** On a group with an active enrollment, tap the enrollment → the 2-item menu appears (try all three entry points). Open **Edit enrollment** → change days/time/start date, then try changing the group and the study → confirm the **preview** lists the impact → **Save** and verify it sticks. Check pickers pre-select current values, back chevrons return you correctly, there's no infinite spinner, and the row is **disabled** for an enrollment you don't own.

### 2. Switch a study to Draft — confirmation · monday#12268464531
- Switching a **published** study back to **Draft** while groups are enrolled now shows a **confirmation** that explains enrolled groups **keep their lessons**; only *new* enrollments are blocked (no group is kicked out).

**QA:** Publish a study → enroll a group → tap the **Published** badge → **Switch to Draft**. A confirm appears naming how many groups are enrolled. Cancel and Switch-to-Draft both behave. With **no** groups enrolled, it switches straight to draft (no extra prompt).

### 3. Study & activity editors
- **Program Home tab renamed** "Studies" → **"Lessons"** (monday#12268465402).
- **Read editor:** the bare "+" is now labeled **"Add Bible verse"** / **"Add custom text"** buttons (monday#12268478769).
- **Activity title capped at 200 chars** in the input, so an over-long title can't silently fail the save (monday#12297338039).
- **Exegesis editor:** highlighting text that **overlaps an existing highlight** now **merges** into it instead of throwing "couldn't save" (monday#12572733385).
- **Select Group** card selected-style now matches **Select Program**.

**QA:** Program Home shows a **Lessons** tab. In a Read lesson, the editor shows the two labeled Add buttons. Type a title past 200 chars → it stops at 200 and **Save succeeds**. In an Exegesis lesson, highlight over an existing highlight → note merges, **no error**. Select-Group and Select-Program cards look identical when selected.

### 4. Unenroll
- Success overlay now uses the **green checkmark** (not the warning triangle) (monday#12344966853).
- Unenrolling **updates the Enrolled tab immediately** (store is pruned) (monday#12344966891).

**QA:** Groups → **Enrolled** → swipe an enrollment → **trash** → confirm. Expect a **green checkmark** and the card **disappears from the Enrolled tab right away**.

### 5. Profile / environment (Debug/QA builds only)
- **Robust Local-environment switching + connection test** on the Profile screen.

**QA (Debug builds):** Profile → environment switcher → **Local** → run the connection test; switching between environments is reliable.

## 🔌 Backend / API — affects in-app behavior

- **Enrollment-edit endpoints** (reschedule, group change, **study swap** with history-preserving removal, **impact preview**) — these power the new Edit-enrollment flow above (monday#12270302158).
- **New enrollments default to AUTO sync** — published curriculum updates now reach members automatically instead of needing a manual step (monday#12268576962).
- **Enrollment lists filter out soft-deleted studies** — a deleted study stops appearing in enrollment/member lists (monday#12415690223).
- **Enrollment progress fix** — a lesson with **no activities** no longer counts as perpetually "incomplete," and lesson totals now use the group's **scheduled** lessons rather than the study's live day count (monday#12268464531). *(Most visible on the web member group-home, but it's the same API the app reads.)*
- **Image pipeline emits WebP** alongside JPEG variants — images may load smaller/faster (monday#12572712291).

**QA:** Create an enrollment from the app → confirm added study days later reach the member (AUTO sync). Delete a study → it drops out of enrollment lists. Enrollment progress counts look right after editing a study.
