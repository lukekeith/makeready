## 2026-09-12T02:28:29.097Z

I would prefer the thickenss of the bar is done with a t-shirt size where the thin variant in figma is the sm and the thick variant is the lg, we just need one inbetween for md. I want the calling surface to have control over the color as an override, but the default pattern will be a value of 0 - 1 where there are thresholds for red, yellow, and green. The prop structure should allow these thresholds to be set at whatever value they want. There should also be a prop to set whether or not we are filling with a gradiation or filling solid.

I also want an animation prop that controls the bar's animation when viewed, which would be the the bar filling from 0 -> it's value at a duration with an easing function.

If it's a gradiation fill, then if the bar is 90%, it would gradiate from the red threshold -> yellow threshold -> green threshold and interpolate all the colors inbetween. The thresholds should also be a value between 0 - 1 and the user can technically put them in any order, but there should be a default applied 0.2 red, 0.4 yellow 0.7 green
