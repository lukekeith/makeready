# action not as expected

## Problem
iPhone day editor: tapping "+" opens the Select-activity menu; picking a type
creates the activity on the SERVER but it never appears in the activity list —
only after exiting and re-entering ("I'll need to exit and re-enter"). Root
cause is on the ENROLLMENT day editor (EditEnrollmentDay): the local-state
append in `EnrollmentActions.addScheduledActivity` is wrapped in
`if let entry = state.lessonScheduleMap[scheduleId]` — a LEGACY map populated
only by Home/Calendar loading (HomeActions), NOT by the Group → enrollment →
lessons path (`loadEnrollmentDetails` populates `scheduledLessons` only). When
the map has no entry the whole append silently skips: no error, server 201,
UI unchanged. Fixed = the new activity appears immediately in the list (and
the same conditional-append defect in `reorderScheduledActivities` is
corrected with it).

## Root cause
`EnrollmentActions.addScheduledActivity` (EnrollmentActions.swift:698-711):
after the successful POST, BOTH local writes (append into the
`state.scheduledLessons[lesson.id]` aggregate the editor renders from, and the
legacy `lessonScheduleMap` patch) live inside
`if let entry = state.lessonScheduleMap[scheduleId]`. The Group → enrollment →
lessons path warms only `scheduledLessons` (`loadEnrollmentDetails`,
EnrollmentActions.swift:155-166); `lessonScheduleMap` is only populated by
HomeActions (calendar/home cards). So unless the user happened to load
Home/Calendar data covering this schedule first, the guard fails and the
append silently no-ops — explaining both the symptom and its intermittency
("similar to a previous problem"). `reorderScheduledActivities` (:729-753)
repeats the pattern.

## Verification
- **Code-level proof (strongest):** EnrollmentActions.swift:701
  (`if let entry = state.lessonScheduleMap[scheduleId] {` wrapping the
  `scheduledLessons.upsert`) vs :155-166 (`loadEnrollmentDetails` never
  writing `lessonScheduleMap`).
- **Manual repro (simulator, local stack):** fresh launch (or after killing
  the app) → Groups → group → enrollment → lessons → open a day → "+" →
  pick a type → activity does NOT appear; back out and re-enter the day →
  it's there. Visiting Home/Calendar first can mask it.
- **Fixed looks like:** the new activity card animates into the list
  immediately, on every navigation path.
